# Hand-written Baseline Profile for Oro.
#
# Shipped through androidx.profileinstaller: on install (or on first launch for
# sideloaded APKs) ART AOT-compiles the methods matched here instead of
# interpreting/JIT-ing them, which is most noticeable on low-end phones where
# the JIT warms up slowly. AGP rewrites these rules through the R8 mapping, so
# they keep working on minified release builds.
#
# The AndroidX/Compose libraries ship their own profiles; this file only covers
# Oro's code on the cold-start path and the screens/components that are hot
# while the user works (home list, editor, chat, file tree, diffs, markdown).
#
# Syntax: H = hot, S = startup, P = post-startup. `pkg/**->**(**)**` matches
# every method of every class under pkg (any depth); `pkg/*->` only the
# classes directly in pkg. Exact classes use the `Lpkg/Name;->` form.
