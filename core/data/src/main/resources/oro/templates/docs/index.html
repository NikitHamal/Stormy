Getting started

Introduction

Lumen is a 9 KB charting library for the web. It draws crisp, accessible SVG charts from plain arrays, with no build step and no dependencies.

New in 3.2

Charts now announce their summary to screen readers automatically. See Accessibility.

Installation

Add Lumen from a CDN, or install it with your package manager.

HTML
<script src="https://cdn.example.com/lumen@3.2/lumen.min.js"></script>
Terminal
npm install lumen-charts

Your first chart

Give Lumen an element and your data. Labels and values are plain arrays.

JavaScript
const chart = Lumen.bar('#sales', {
  labels: ['Mon', 'Tue', 'Wed', 'Thu', 'Fri'],
  values: [12, 19, 8, 24, 16],
  format: (v) => v + ' orders'
});
Heads up

The element needs a height. Lumen fills its container, so a zero-height box draws nothing.

Shaping data

Lumen expects one value per label. Group and sum your records first — a small reducer is usually enough.

JavaScript
const byDay = orders.reduce((acc, o) => {
  acc[o.day] = (acc[o.day] || 0) + o.total;
  return acc;
}, {});

Theming

Every colour is a CSS custom property, so charts follow your design system and dark mode for free.

PropertyDefaultControls
--lumen-bar#6d5dfcBar and line colour
--lumen-grid#e2e8f0Grid lines
--lumen-textcurrentColorAxis labels

Accessibility

Each chart renders a hidden data table and a one-sentence summary. Keyboard users can step through points with the arrow keys.

API

Lumen.bar(target, options) and Lumen.line(target, options) return a chart with update(data) and destroy().
